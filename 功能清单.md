# ALE-AAM 功能清单

**核心能力就是：加载数据 → 查看环境 → 交互式画航线 → 导出 GeoJSON**

数据有两种加载方式：

- 启动服务时通过 `--scenario` 绑定包含 DEM、建筑、空域、气象、人口和应急点的场景目录。
- 在 Web 页面中直接加载本地 GeoJSON，或加载包含未压缩 GeoJSON 的 ZIP。`20260724_03.zip` 可直接加载，数据仅在浏览器本地解析，不上传、不访问在线地图。

## 1. GIS 数据图层加载与分层管理

### 1.1 图层加载

| 功能         | 说明                 |
| ---------- | ------------------ |
| 加载 DEM 栅格  | 导入数字高程模型             |
| 加载 3D 建筑矢量 | 导入带高度属性的建筑物数据      |
| 加载空域管制区    | 导入禁飞区、限高区等多边形数据    |
| 加载气象栅格     | 导入风速、风向、能见度等气象网格数据 |
| 加载人口密度栅格   | 导入地面人口密度热力图        |

### 1.2 图层管理

| 功能      | 说明                                             |
| ------- | ---------------------------------------------- |
| 图层显隐切换  | 独立控制每个图层的显示/隐藏                                 |

## 2. 地图浏览与空间查看

| 功能     | 说明                           |
| ------ | ---------------------------- |
| 缩放与平移  | 浏览地图不同区域和比例尺                 |
| 坐标定位   | 在地图上输入并定位特定经纬度坐标（如起降点）       |
| 要素属性查看 | 点击查看图层中要素的属性信息（如建筑高度、空域限制类型） |


---

### 3. 航线规划

| 功能      | 说明                  |
| ------- | ------------------- |
| 交互式航点放置 | 在地图上点击放置航点，构建有序航线序列 |
| 航点属性设置  | 为航点配置高度、速度等参数       |
| 航线可视化   | 将航点自动连接为可视化的航线      |
| 航点编辑    | 调整航点位置或删除航点         |

---

### 4. 数据导出

| 功能 | 说明 |
|------|------|
| 导出 GeoJSON | 将绘制的航线导出为 GeoJSON 格式的 Feature（LineString 几何类型） |
